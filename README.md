# Путешествие мечты

Домашнее задание №1 «Анкета». Нативное приложение на **.NET MAUI 10**, XAML и C#. Тема: предпочтения путешественника.

Анкета собирает имя, бюджет, направление, темп отдыха, дату, длительность, интересы, необходимость гида и пожелания. Приложение работает локально; ответы используются только для сводки на экране.

## Запуск

Нужны .NET 10 SDK и инструменты MAUI для выбранной платформы. Версия соответствует учебному проекту [Rews/MAUIApp2026](https://github.com/Rews/MAUIApp2026).

### Windows

Установите рабочую нагрузку .NET MAUI через Visual Studio Installer, откройте `TravelSurvey.csproj` и выберите Windows Machine. Либо выполните:

```powershell
dotnet workload install maui-windows
dotnet build TravelSurvey.csproj -f net10.0-windows10.0.19041.0 -p:TargetFrameworks=net10.0-windows10.0.19041.0 -t:Run
```

### Android

Установите .NET MAUI, Android SDK, совместимый JDK и запустите эмулятор либо подключите устройство:

```sh
dotnet workload install maui-android
dotnet build TravelSurvey.csproj -f net10.0-android -p:TargetFrameworks=net10.0-android -t:Run
```

### macOS / iOS

Нужны совместимый Xcode и рабочие нагрузки MAUI:

```sh
dotnet workload install maui
dotnet build TravelSurvey.csproj -f net10.0-maccatalyst -p:TargetFrameworks=net10.0-maccatalyst -t:Run
```

Для iOS выберите устройство или симулятор в IDE. Подробности настройки окружения: [официальная инструкция Microsoft](https://learn.microsoft.com/dotnet/maui/get-started/installation?view=net-maui-10.0).

## Поведение

- «Показать результат» проверяет два обязательных поля: непустое имя и бюджет больше нуля. Ошибки отображаются рядом с кнопками. Запятая и точка допустимы как десятичный разделитель бюджета.
- Когда обязательные поля заполнены корректно, появляется подсказка о готовности анкеты.
- Результат включает **все ответы**, в том числе отсутствие выбора и необязательных пожеланий.
- Любое изменение ответа скрывает прежнюю сводку, чтобы она не показывала устаревшие данные.
- «Очистить» возвращает исходное состояние: пустые имя, бюджет и пожелания; направление не выбрано; темп «Всего понемногу»; флажки и гид выключены; дата 09.10.2026; длительность 7 дней; результат и ошибки скрыты; прокрутка возвращается наверх.

## Соответствие заданию

Все обязательные свойства указаны непосредственно в `MainPage.xaml`, обработчики находятся в `MainPage.xaml.cs`.

| Требование | Реализация |
| --- | --- |
| 2+ Label: Text, FontSize, FontAttributes | Подписи и заголовки |
| 2 Entry: Placeholder, Keyboard, MaxLength | Имя (`Default`, 60) и бюджет (`Numeric`, 8) |
| Editor: Placeholder, AutoSize, MaxLength | Пожелания, `TextChanges`, 500 символов |
| Picker: Title и минимум 3 варианта | 4 направления |
| 3 RadioButton: Content, GroupName, Value | Одна группа `TravelPace` |
| 2 CheckBox: IsChecked, Color | Экскурсии и местная кухня |
| Switch: IsToggled, OnColor | Нужен гид |
| DatePicker: Format, Date, MinimumDate, MaximumDate | `dd.MM.yyyy`, 09.10.2026, диапазон 2026-2035 |
| Stepper: Minimum, Maximum, Value, Increment | 1-30 дней, исходно 7, шаг 1 |
| Image: Source, Aspect, HeightRequest | Собственная SVG-иллюстрация; в MAUI преобразуется в `journey.png` |
| 2 Button: Text, Clicked | Показать результат, Очистить |
| Grid с явными строками, столбцами и позициями детей | Длительность, интересы, гид |
| StackLayout со Spacing, Margin и Padding | Все разделы анкеты |
| ScrollView | Все поля и результат доступны при прокрутке |
| Имена элементов | У каждого элемента и контейнера уникальный `x:Name` |
| x:Reference, Path и Mode | Значение Stepper привязано к Label; Switch - к видимости подсказки |
| IsVisible зависит от заполнения | Подсказка о готовности обязательных полей |
| Логика в code-behind | Проверка, события, сводка и очистка в `MainPage.xaml.cs` |

## Проверка

```sh
python3 scripts/check_requirements.py
```

Скрипт проверяет XAML, число контролов, явные свойства, уникальность имён, группы, диапазоны, привязки и наличие обработчиков. GitHub Actions запускает эту проверку и собирает Windows-приложение.

Ручные сценарии для запуска на устройстве:

1. Пустая анкета: нажать «Показать результат» - две ошибки, сводки нет.
2. Ввести имя и бюджет `0`, отрицательное число или текст - ошибка бюджета.
3. Ввести имя и положительный бюджет - подсказка о готовности; сводка содержит все поля.
4. Проверить дробный бюджет с точкой и запятой.
5. Выбрать направление, другой темп, оба интереса, гида, дату, длительность и пожелания - каждый ответ отражается в сводке.
6. Изменить любой ответ после показа сводки - прежний результат скрывается.
7. Нажать «Очистить» - все ответы и состояние восстанавливаются, включая дату и длительность.
8. На небольшом экране прокрутить до последнего поля, кнопок и результата.

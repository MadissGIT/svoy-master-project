# Учебные приложения MAUI

Здесь два отдельных задания:

- `Homework/MovieSurvey` — анкета «Предпочтения в кино».
- `Project/SvoyMaster` — первая версия приложения «СвойМастер».
- `Prototype/index.html` — кликабельный прототип «СвойМастера». Откройте файл в браузере.
- `docs/project-passport.md` — паспорт проекта и сценарий показа.
- `docs/project-passport.pptx` — презентация паспорта для защиты.
- `docs/submission-checklist.md` — проверка требований и порядок сдачи.

## Как запустить

Нужны .NET 10 SDK и инструменты .NET MAUI для выбранной платформы.
На Windows можно открыть `StudyApps.sln` в Visual Studio с установленной нагрузкой MAUI.
На Mac можно использовать VS Code с расширением .NET MAUI или Rider. Для iOS и macOS нужен Xcode.

Выберите `MovieSurvey` или `SvoyMaster` запускаемым проектом, затем устройство или эмулятор.

Пример сборки Android из корня репозитория:

```sh
dotnet build Homework/MovieSurvey/MovieSurvey.csproj -p:TargetFrameworks=net10.0-android
dotnet build Project/SvoyMaster/SvoyMaster.csproj -p:TargetFrameworks=net10.0-android
```

В проектах предусмотрены Android, iOS, Windows и macOS. Собраны Android APK. Остальные платформы пока не проверены.

## Анкета

Обязательны имя и возраст от 6 до 100 лет. Кнопка «Показать результат» выводит все ответы. «Очистить» возвращает исходные значения.

Все элементы и обязательные свойства находятся в `MainPage.xaml`, обработчики — в `MainPage.xaml.cs`. Есть Grid, ScrollView и привязка значения Stepper через `x:Reference`. Каждый элемент интерфейса и контейнер имеет уникальный `x:Name` вида `_Name_`.

## СвойМастер

Учебная версия работает на одном устройстве. В роли клиента можно найти мастера и создать заявку. В кабинете мастера можно выбрать любого из четырёх мастеров.

Мастер принимает заявку и отмечает работу выполненной. Клиент подтверждает результат. Если автоплатёж включён, появляется учебная отметка об оплате.

Данные сохраняются локально в JSON через Preferences. У приложения нет сервера и настоящих аккаунтов. Госуслуги и оплата только демонстрируются. Деньги не списываются, данные Госуслуг не запрашиваются.

Команда и вклад участников указаны в [паспорте](docs/project-passport.md).

Настройка среды: [инструкция Microsoft](https://learn.microsoft.com/dotnet/maui/get-started/installation?view=net-maui-10.0).
